# 名偵探柯南集數整理 - 動畫集數資料庫

一個專為動畫迷打造的集數查詢和管理平台，目前支援《名偵探柯南》和《間諜家家酒》兩部作品。

## 🎯 功能特性

### 核心功能
- **集數查詢** - 支援按集數、標題、漫畫卷數等多維度搜尋
- **中日文標題** - 同時顯示中文和日文標題，方便不同語言使用者
- **對應漫畫** - 清晰標註每集對應的漫畫卷數或話數
- **最愛收藏** - 標記喜愛的集數，本地 IndexedDB 自動保存
- **虛擬滾動** - 優化大列表渲染性能，流暢瀏覽數千集集數

### 動畫支援

#### 《名偵探柯南》
- **總集數**：1194 集
- **內容**：官方版動畫 + 海外版動畫
- **漫畫對應**：完整對應漫畫卷數（Vol. 1~104+）

#### 《間諜家家酒》
- **總集數**：50 集
- **季度分佈**：第 1 季（25 集）/ 第 2 季（12 集）/ 第 3 季（13 集）
- **漫畫對應**：對應漫畫話數、動畫原創、短篇、番外等

## ⚡ 性能優化

### 已實現的優化
1. **延遲計算** - 簡體中文版本在需要時才轉換，減少初始加載
2. **搜尋緩存** - 搜尋結果緩存，避免重複計算
3. **防抖機制** - 最愛操作防抖，減少 IndexedDB 寫入頻率
4. **虛擬滾動** - 只渲染可見區域的集數卡片
5. **React.memo** - 集數卡片組件優化，避免不必要的重新渲染
6. **Context 穩定化** - 使用 useMemo 確保 Context 值不頻繁變化

### 性能指標
- 初始加載時間：< 1s
- 搜尋響應時間：< 100ms（含緩存）
- 虛擬滾動流暢度：60 FPS

## 📝 資料格式

### 集數資料結構
```typescript
interface AnimeEpisode {
  episode: number;           // 集數
  season?: number;           // 季度（可選）
  seasonEpisode?: number;    // 季內集數（可選）
  title: string;             // 中文標題
  titleJa: string;           // 日文標題
  manga?: string;            // 對應漫畫
  aired?: string;            // 播出日期（可選）
  rating?: number;           // 評分（可選）
}
```

### 漫畫話數格式
- 單話：「第 1 話」
- 多話：「第 1~3 話」
- 混合：「第 1~2 話 / 動畫原創 / 短篇 3」
- 番外：「番外 1 / 短篇 1」
